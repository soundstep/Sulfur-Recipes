# Quick Task 20260428-001: Free Hosting Research

## Goal

Identify the best free hosting option for the Sulfur Recipes app — a React/Vite frontend and an Express.js API server running in a pnpm monorepo.

## Research Output

See: `20260428-001-RESEARCH.md` for the full platform comparison.

## Summary of Findings

**Recommendation: Render (free tier)**

- Free Static Site for the React/Vite frontend (CDN-backed, instant deploys)
- Free Web Service for the Express API (Node 24, 512 MB RAM)
- Supports pnpm monorepo via `render.yaml` with `rootDir` per service
- API sleeps after 15 min idle (cache lost on wake — acceptable)
- 750 free instance-hours/month (sufficient with sleep behavior)

**Runner-up: Vercel (frontend) + Render (API)**
Best DX for frontend deploys; Render handles the API.

**Power option: Oracle Cloud Always Free**
No sleep, persistent cache, 4 cores / 24 GB RAM — but high DevOps effort.

## Platforms to Avoid

- Glitch — shut down July 2025
- Cyclic.sh — shut down late 2024
- Koyeb — no free tier ($29/mo minimum)
- Fly.io — no free tier for new accounts since Oct 2024
