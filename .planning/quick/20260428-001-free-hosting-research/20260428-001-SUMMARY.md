# Quick Task 20260428-001 — Summary

## What Was Done

Researched free hosting platforms for the Sulfur Recipes app (React/Vite frontend + Express.js API, pnpm monorepo, Node 24, no DB, in-memory cache).

## Outcome

**Top recommendation: Render (free tier)**

Both services can be hosted for free on Render:
- **Frontend:** Render Static Site — global CDN, auto-deploys from Git
- **API:** Render Free Web Service — Node 24, 512 MB RAM, sleeps after 15 min idle

Full details and platform comparison in: `20260428-001-RESEARCH.md`

## Key Decisions for Future Deployment

| Decision | Choice |
|---|---|
| Frontend host | Render Static Site (or Vercel Hobby if better DX desired) |
| API host | Render Free Web Service |
| Sleep mitigation | UptimeRobot ping every 14 min (optional) |
| Build config | `render.yaml` with `rootDir` per service + pnpm install in build cmd |

## Platforms Eliminated

Glitch (dead), Cyclic (dead), Koyeb (no free tier), Fly.io (no free tier for new users).
