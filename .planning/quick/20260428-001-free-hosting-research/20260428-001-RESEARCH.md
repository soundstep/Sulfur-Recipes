# Free Hosting Research — Sulfur-Recipes (Single Full-Stack Service)

> **Researched:** April 28, 2026
> **Constraint:** Single deployment — Express serves both `/api/*` routes AND the Vite `dist/` static files
> **Stack:** React + Vite frontend · Express.js API (Node 24, in-memory cache, wiki scraper) · pnpm monorepo · No DB

---

## Key Constraint

The Express server caches scraped data **in memory** with a 1h TTL. Platforms that spin down the container lose the cache on wake-up. This is acceptable but means the first request after sleep triggers a fresh scrape (~1–2s latency).

**Serverless/lambda is not viable** — stateless invocations cannot maintain an in-memory cache across requests.

## Top Recommendations

### 🥇 #1 — Render (easiest, truly free, with keep-alive workaround)

- **Deployment:** Single Node Web Service. Express builds the frontend in the build step and serves `dist/` as static files.
- **Sleep:** Spins down after 15 min idle. Fix with UptimeRobot (free) pinging `/health` every 10 min — cache then persists indefinitely in practice.
- **Build command:** `npm install -g pnpm && pnpm install --frozen-lockfile && pnpm --filter @sulfur/web build`
- **Start command:** `node packages/api/dist/index.js` (Express serves `../web/dist` as static)
- **RAM:** 512 MB — comfortable for this app
- **Node 24:** Set `NODE_VERSION=24` env var
- **Limits:** 750 free instance-hours/month (one service easily fits)

```yaml
# render.yaml
services:
  - type: web
    name: sulfur-recipes
    runtime: node
    buildCommand: npm install -g pnpm@latest && pnpm install --frozen-lockfile && pnpm --filter @sulfur/web build
    startCommand: node artifacts/api-server/dist/index.js
    plan: free
    envVars:
      - key: NODE_ENV
        value: production
      - key: NODE_VERSION
        value: "24"
```

Express must serve the frontend dist — add to `artifacts/api-server/src/index.ts`:
```ts
import path from 'path'
import express from 'express'

// Serve frontend build (adjust path to your monorepo layout)
app.use(express.static(path.join(__dirname, '../../sulfur-recipe-finder/dist')))

// SPA fallback
app.get('*', (req, res) => {
  res.sendFile(path.join(__dirname, '../../sulfur-recipe-finder/dist/index.html'))
})
```

### 🥈 #2 — Northflank Sandbox (no sleep, zero ops)

- No cold starts, no cache loss
- Free sandbox tier: 2 services, always-on
- GitHub integration, Buildpacks or Dockerfile
- Caveat: sandbox RAM limits not publicly documented — verify it handles `pnpm install + vite build`
- Worth trying if Render's sleep behavior is annoying

### 🥉 #3 — Oracle Cloud Always Free (maximum power, maximum setup)

- Truly always-on — no sleep, cache persists indefinitely
- Ampere A1 ARM: up to 4 OCPU / 24 GB RAM free
- Full control: Node 24, pnpm, systemd, Nginx for SSL
- Downside: significant manual DevOps (SSL, reverse proxy, deployments)
- A1 ARM capacity often unavailable in popular regions (us-ashburn-1) — try `ap-osaka-1` or `eu-frankfurt-1`
- **Best choice if you want zero cold starts and no monthly limits**

## Architecture (Single Service)

```
USER BROWSER
     │
     ▼
┌────────────────────────────────────┐
│  Express.js (Node 24)              │
│  artifacts/api-server              │
│                                    │
│  GET /api/*  → scrape + cache      │
│  GET /*      → serve dist/index.html│
│  static      → dist/ assets        │
└────────────────────────────────────┘
         │
         ▼
   sulfur.wiki.gg  (scraped, 1h TTL)
```

Build order:
1. `pnpm --filter @sulfur/web build` → `artifacts/sulfur-recipe-finder/dist/`
2. `pnpm --filter @sulfur/api build` → `artifacts/api-server/dist/`
3. Express start: serves both

## Pitfalls

### Sleep + cache loss (Render, HF Spaces)
First request after 15-min idle triggers fresh scrape. Mitigate:
- UptimeRobot free tier → ping `/health` every 10 min (prevents sleep entirely)
- Or accept the cold-start scrape — it's fast enough

### pnpm on Render
Render uses npm by default. Prepend to build command:
```bash
npm install -g pnpm@latest
```

### Monorepo path resolution
Express `static()` path must point to the frontend `dist/` relative to where the server process runs. Test locally with `NODE_ENV=production node dist/index.js` from the repo root before deploying.

### Node 24 on Render
Set env var `NODE_VERSION=24`. Render supports it.

### Oracle Cloud A1 ARM availability
`us-ashburn-1` and `us-phoenix-1` are frequently out of capacity. Try: `ap-osaka-1`, `eu-frankfurt-1`, `sa-saopaulo-1`. Script to keep retrying provisioning is common practice.
