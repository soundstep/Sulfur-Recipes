Update `artifacts/api-server/src/app.ts` to serve the Vite frontend build.

The frontend build output (`dist/public/`) will be placed adjacent to the server's `dist/` at runtime:
- Server dist: `/app/dist/index.mjs`
- Frontend static: `/app/public/` (copied there in the Dockerfile)

Add after the `/api` router mount:

```typescript
import path from "path";
import { fileURLToPath } from "url";

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const publicDir = path.resolve(__dirname, "../public");

// Serve frontend static files
app.use(express.static(publicDir));

// SPA fallback — serve index.html for all non-API routes
app.get("*", (_req, res) => {
  res.sendFile(path.join(publicDir, "index.html"));
});
```

Key points:
- `/api` route is mounted BEFORE static/SPA — API takes priority
- `publicDir` resolves to `/app/public` at runtime (the Dockerfile will COPY the Vite build there)
- The SPA fallback must be the LAST route — after static and after /api
- In dev (without Docker), `public/` won't exist — Express will simply 404 on non-API routes which is fine for API development

Create `Dockerfile` at the repo root with 3 stages.

```dockerfile
# ── Stage 1: Build the frontend ──────────────────────────────────────────────
FROM node:24-alpine AS fe-builder
RUN corepack enable && corepack prepare pnpm@latest --activate
WORKDIR /app

# Workspace manifests (layer cache)
COPY package.json pnpm-workspace.yaml pnpm-lock.yaml ./
COPY lib/api-zod/package.json ./lib/api-zod/
COPY lib/api-spec/package.json ./lib/api-spec/
COPY lib/api-client-react/package.json ./lib/api-client-react/
COPY artifacts/sulfur-recipe-finder/package.json ./artifacts/sulfur-recipe-finder/
RUN pnpm install --frozen-lockfile

# Source + assets
COPY lib/ ./lib/
COPY attached_assets/ ./attached_assets/
COPY artifacts/sulfur-recipe-finder/ ./artifacts/sulfur-recipe-finder/

WORKDIR /app/artifacts/sulfur-recipe-finder
RUN pnpm run build
# Output: /app/artifacts/sulfur-recipe-finder/dist/public/

# ── Stage 2: Build the API server ────────────────────────────────────────────
FROM node:24-alpine AS api-builder
RUN corepack enable && corepack prepare pnpm@latest --activate
WORKDIR /app

COPY package.json pnpm-workspace.yaml pnpm-lock.yaml ./
COPY lib/api-zod/package.json ./lib/api-zod/
COPY artifacts/api-server/package.json ./artifacts/api-server/
RUN pnpm install --frozen-lockfile

COPY lib/api-zod/ ./lib/api-zod/
COPY artifacts/api-server/ ./artifacts/api-server/

WORKDIR /app/artifacts/api-server
RUN pnpm run build
# Output: /app/artifacts/api-server/dist/index.mjs

# ── Stage 3: Runtime ─────────────────────────────────────────────────────────
FROM node:24-alpine AS runner
RUN corepack enable && corepack prepare pnpm@latest --activate
WORKDIR /app

# API server bundle + pino worker files
COPY --from=api-builder /app/artifacts/api-server/dist ./dist
# node_modules needed at runtime (pino thread-stream)
COPY --from=api-builder /app/node_modules ./node_modules

# Frontend static files served by Express
COPY --from=fe-builder /app/artifacts/sulfur-recipe-finder/dist/public ./public

ENV NODE_ENV=production
EXPOSE 3000
CMD ["node", "--enable-source-maps", "./dist/index.mjs"]
```

Notes:
- Express in app.ts serves `./public` (relative to dist/index.mjs → resolves to `/app/public`)
- PORT is injected at runtime via docker-compose — not set here (app throws if absent)
- pino needs thread-stream workers from node_modules — the full node_modules from api-builder is sufficient

|----------|-------------|
| Build-time COPY | Only repo files copied — no secrets baked into layers |
| Runtime PORT | Injected by docker-compose, never hardcoded |
